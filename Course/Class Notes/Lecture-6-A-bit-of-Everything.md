## Part 1: QUANT VALUE STRATEGIES

### The quant value space: why does it matter for search?

#### 1) Value Premium
- **统计学发现**: 相对于基本面具有低估值的股票（价值股）比相对于基本面具有高估值的股票（成长股）具有更高的回报率

#### 2) Value Premium Puzzle
- **谜题**: 这些价值股看起来并不比成长股更有风险：更高的回报率似乎并不是对风险的补偿（按照CAPM的测量方法）

#### 3) Implications
- **启示**: 基于估值比率的筛选是预测投资想法的有用工具

### Gene Fama: Father of quant

### The definition of value … for a quant

- 回顾企业运营业务在时间 $t$ 的价值 $V_t$：

$$V_t = A_t + \text{Growth Options}$$

- 因此，$\frac{V_t}{A_t} > 1$ 当且仅当 Growth Options > 0

#### Value and growth for the quant

1. **"Value"** ⇾ $\frac{V_t}{A_t} \leq 1$：市场价值低于账面价值
2. **"Growth"** ⇾ $\frac{V_t}{A_t} > 1$：市场价值高于账面价值

#### Tobin's q

$$q_t = \frac{V_t}{A_t}$$

- 按照 $\frac{1}{q_t} = \frac{A_t}{V_t}$ 对股票进行排序：价值股还是成长股获得更高回报？
  - Market value (or ME)
  - Book value (or BE)

### 📌 Q&A 1: 关于第10页的风险-回报曲线图

**问题**：课件第10页的图长得怎么那么像学CML（资本市场线）或最佳资本线的图？我觉得是一个左边凸起的线，还会有一个切线。图本身的意思是不是说极端的价值和极端的成长股都并不是最好的选择，应该是这两个混合起来会有一个最佳点，在那里风险达到最小，同时还能有不错的回报？

**回答**：你的理解非常准确！这张图确实和现代投资组合理论（MPT）中的**有效前沿（Efficient Frontier）**或**资本市场线（CML）**的概念非常相似。

**关键要点**：

1. **曲线形状**：左凸的曲线代表了**风险-回报权衡**
   - 横轴通常是风险（标准差/波动率）
   - 纵轴是预期回报

2. **极端不是最优**：
   - **100%价值股**：可能有价值陷阱风险，某些价值股长期低估是有原因的
   - **100%成长股**：估值过高，泡沫风险，对增长预期过于乐观
   - 两个极端都可能导致较差的风险调整后回报

3. **最优组合点**：
   - 曲线上靠近顶部（或切点）的位置代表**夏普比率最大化**的组合
   - 这个点实现了：
     - 在给定风险水平下回报最高
     - 或在给定回报水平下风险最低

4. **实践意义**：
   - 价值和成长的**适当混合**可以：
     - 分散单一策略风险
     - 捕捉不同市场环境下的机会
     - 避免极端风格暴露
   - 这就是为什么很多成功的投资者（包括巴菲特的演变）会说"成长与价值不应该分离"
   - 最佳投资往往是**合理价格买入的优质成长公司**（Growth at a Reasonable Price - GARP）

### 📌 Q&A 2: Fama-French因子的风险-回报特征和评估方法

**问题**：以第10页的图片来说，在Fama-French的因子当中，Market和Momentum、Value都是波动性很高（风险很高）但回报也很高的品种对吗？那这几个因子本身的好坏怎么衡量呢？看夏普比率吗？也就是市值因子和动量因子最好？还是有其他什么办法吗？它们看着都是线性的，风险越大，回报越好。

**回答**：

#### 1. 各因子的风险-回报特征

**并非所有因子都是"高风险高回报"**：

- **Market (市场因子/Beta)**：是的，高风险高回报，这是CAPM的基础
- **Value (价值因子/HML)**：中等波动，历史上有显著溢价
- **Size (规模因子/SMB)**：小公司确实波动更大，但溢价在近年减弱
- **Momentum (动量因子/UMD/WML)**：**最高波动**，但历史回报也很高，有"崩溃风险"（crash risk）
- **Profitability/Quality (盈利能力/质量)**：**相对低波动**，但仍有正溢价（这是关键发现！）

#### 2. 如何衡量因子的好坏？

**不能只看绝对回报！应该看风险调整后的回报**

**主要评估指标**：

1. **夏普比率 (Sharpe Ratio)** - 最常用：
   $$\text{Sharpe Ratio} = \frac{E[R] - R_f}{\sigma}$$
   - 衡量每单位总风险的超额回报

2. **信息比率 (Information Ratio)**：
   $$\text{IR} = \frac{\alpha}{\sigma_{\text{tracking error}}}$$
   - 相对于基准的超额回报除以跟踪误差

3. **t统计量**：
   - 平均回报的统计显著性
   - $t > 2$ 通常认为显著（95%置信度）
   - 衡量因子溢价是否真实存在

4. **最大回撤 (Max Drawdown)**：
   - 峰值到谷底的最大跌幅
   - Momentum因子的致命弱点（可能在市场转折时暴跌）

#### 3. 各因子的历史表现对比

| 因子 | 年化回报 | 波动率 | 夏普比率 | 特点 |
|------|---------|--------|---------|------|
| **Market** | ~8-10% | 15-20% | ~0.4-0.5 | 基础因子 |
| **Value** | ~3-5% | 10-15% | ~0.3-0.4 | 近年表现差 |
| **Momentum** | ~5-8% | 15-25% | ~0.4-0.6 | 高波动，有崩溃风险 |
| **Quality/Profitability** | ~3-4% | 8-12% | ~0.4-0.5 | **低波动，稳定** ⭐ |
| **Size** | ~2-3% | 10-15% | ~0.2-0.3 | 溢价减弱 |

#### 4. 重要发现：低风险异象 (Low Risk Anomaly)

**这是投资界的"圣杯"发现**：

- **Quality/Profitability因子**：风险较低但回报不错
- **违反传统"高风险高回报"的理论**
- 可能原因：
  - 机构投资者的杠杆约束（无法充分利用低风险资产）
  - 散户投资者偏好"彩票式"高波动股票
  - 行为偏差（过度自信、赌博心理）

#### 5. 关键结论

**不是"风险越大回报越好"，而是"风险调整后回报最好"**：

- **单一因子**：Momentum夏普比率可能最高，但有严重的尾部风险
- **多因子组合**：通常表现最好，因为：
  - 分散化效应
  - 不同因子在不同市场环境下轮动
  - **Value + Quality** 组合特别受欢迎（避免价值陷阱）
  
#### 6. 当前趋势（2020年代）

从第11-12页的图可以看出：
- Value因子在2010年代表现不佳（"Value has died"争论）
- Quality因子越来越受重视
- **Modern Value = Value + Quality + Moderate Growth**
- 纯粹的low P/B筛选已经不够，需要结合盈利能力

### 📌 Q&A 3: 因子择时困境 - 如何判断因子失效还是周期性低谷？

**问题**：我们从2023年回看，已知过去这么多年价值因子都表现很差，怎么确定接下来还要不要用价值因子？2020年中国"喝酒吃药"（白酒医药等价值白马）表现很好，但其他时期风格完全不同。价值投资本来就是长期的事，但作为因子来讲，如果你每个月rebalance，而这个因子近七八年表现都不好，你还会继续用吗？但不用的话，又怎么知道今年会不会就是反转的大牛市？

**回答**：

这是量化投资中最困难的问题之一：**因子择时（Factor Timing）**。你描述的正是"**因子投资者困境**"。

#### 核心困境

- 价值因子2007-2020年表现极差（尤其2010-2020）
- 但**2022-2023年价值股大幅跑赢成长股**
- **在最黑暗的时刻放弃，往往就错过反转**

#### 1. 如何判断"结构性失效" vs "周期性低谷"？

**A. 结构性失效的信号**：

- **理论基础被颠覆**：
  - 会计准则根本性改变，账面价值意义消失
  - 科技改变商业模式（无形资产主导时代）
  
- **市场结构变化**：
  - 被动投资占比过高（ETF大量资金流入改变价格发现）
  - 算法交易消除了某些异象
  
- **极长时间失效**：
  - 一个因子在多个完整经济周期（20-30年）都不work
  - 需要重新审视理论基础

**B. 周期性低谷的特征**：

- **估值极端分化**：
  - 价值股vs成长股估值差达到历史极值
  - **2020年底正是这种情况**（纳斯达克P/E > 50倍）
  
- **经济环境特殊**：
  - 超低利率环境（2010-2021）→ 成长股估值膨胀
  - 利率正常化→ 价值股复苏（**2022年正是如此**）
  
- **行为金融学逻辑仍成立**：
  - 投资者仍然会犯同样的错误
  - 只是错误的方向和程度在不同时期不同

#### 2. 历史案例：2022-2023年价值因子的大反转

**这正是你问题的关键答案**：

| 时期 | 价值vs成长表现 | 驱动因素 |
|------|---------------|----------|
| 2010-2020 | 价值大幅落后 | 超低利率、科技革命、成长股泡沫 |
| **2022** | **价值暴涨40%+** | 利率飙升至5%、成长股泡沫破裂、价值股估值修复 |
| **2023** | 价值持续跑赢 | 经济韧性超预期、高利率环境持续 |

**⚠️ 如果你在2020年放弃价值因子，你就完美错过了2022年的历史性大反转！**

#### 3. 中国市场案例分析

你提到的"喝酒吃药"现象：

- **2019-2021**：白酒医药（价值白马）暴涨
  - 茅台：800元 → 2600+元
  - 片仔癀、恒瑞医药等大幅上涨
  - "核心资产"、"抱团"概念盛行
  
- **2021年底-2022**：这些股票暴跌50-70%
  - 估值回归均值
  - "抱团瓦解"
  - 风格切换至"困境反转"

**启示**：
- 风格轮动是真实存在的
- 但轮动时点**几乎不可预测**
- 试图择时往往适得其反

#### 4. 实践中的解决方案

**A. 多因子组合（最推荐）** ⭐⭐⭐

**不要孤注一掷在单一因子上**：

```
投资组合 = 40% Value + 30% Quality + 20% Momentum + 10% Low Volatility
```

**优势**：
- 不同因子在不同时期表现不同（轮动效应）
- 分散了因子择时风险
- **Value + Quality 组合特别重要**（避免价值陷阱）
- 即使某个因子低谷，其他因子可能表现好

**B. 动态调整因子权重（但不完全放弃）**

基于**估值spread**进行战术性调整：

```python
估值spread = (成长股P/E) / (价值股P/E)

if 估值spread > 历史90分位数:  # 成长股相对过贵
    价值因子权重 = 50%  # 增加
elif 估值spread < 历史10分位数:  # 价值股相对过贵
    价值因子权重 = 20%  # 降低但不为0
else:
    价值因子权重 = 35%  # 基准权重
```

**关键**：降低权重，但**永远不完全放弃**

**C. 拉长再平衡周期**

你提到"每个月rebalance"可能**不适合价值因子**：

| 再平衡频率 | 适用场景 | 优缺点 |
|-----------|---------|--------|
| **每月** | Momentum因子 | 捕捉短期趋势，但交易成本高 |
| **每季度** | 混合策略 | 平衡成本和效果 |
| **每半年/年** | **Value因子** ⭐ | 符合价值投资长期本质，降低成本 |

**价值投资的本质是长周期**：
- 建议半年或一年rebalance
- 减少交易成本和税收拖累
- 给因子足够时间发挥作用
- 避免被短期波动"震出"

**D. 跟踪宏观领先指标**

不是预测因子本身，而是预测**有利环境**：

| 宏观环境 | 有利因子 | 逻辑 |
|---------|---------|------|
| **利率上升期** | Value, Small Cap | 估值压缩打击成长股 |
| **利率下降期** | Growth, Momentum | DCF估值提升 |
| **经济衰退** | Quality, Low Vol | 防御性需求 |
| **经济复苏** | Value, Cyclicals | 盈利改善预期 |
| **高通胀期** | Value, Commodities | 实物资产保值 |

#### 5. 关于"因子失效"的学术证据

**McLean & Pontiff (2016)** 重要研究：
- 因子在学术论文发表后，效果平均**减弱30-50%**
- 但**不会完全消失**
- 原因：
  1. 套利资金涌入（信息传播）
  2. 但套利有成本和风险限制
  3. **行为偏差难以完全消除**（人性不变）

**结论**：因子溢价会减弱，但不会死亡

#### 6. 实操建议总结

**✅ 应该做的**：

1. **使用多因子组合**，不孤注一掷（核心建议）
2. **降低rebalance频率**至半年或一年（符合价值投资本质）
3. **保持一定价值因子暴露**（15-30%），即使短期表现不佳
4. **结合宏观环境微调权重**（但不是完全择时）
5. **监控估值spread**作为调整信号
6. **强调Value + Quality组合**（避免价值陷阱）

**❌ 不应该做的**：

1. ❌ 频繁根据近期表现切换因子（追涨杀跌）
2. ❌ 完全放弃某个历史上有效的因子
3. ❌ 试图完美预测因子轮动时点（不可能）
4. ❌ 只看1-2年表现就下结论（周期太短）
5. ❌ 每个月高频rebalance价值因子

#### 7. 哲学层面的思考

**Benjamin Graham的名言**：
> "In the short run, the market is a voting machine, but in the long run, it is a weighing machine."

- **短期**（1-3年）：情绪、风格、泡沫主导 → 任何因子都可能失效
- **长期**（7-10年+）：基本面和估值必然回归 → 因子重新发挥作用

**因子投资的悖论**：
- 如果因子效果容易择时，就不会有超额回报
- 正因为**需要忍受长期低谷和质疑**，才有溢价存在
- **痛苦本身就是alpha的来源**
- "Be greedy when others are fearful"

#### 8. 回看2024-2026年（事后验证）

从现在（2026年3月）回看：
- **2020年底放弃价值因子** → 错过2022年40%+的大反转
- **2022-2023年坚持价值因子** → 大幅跑赢市场
- 这完美证明了**在最黑暗时坚持的重要性**

**但这不意味着盲目坚持**：
- 需要理解因子背后的**经济和行为金融学逻辑**
- 需要**组合管理**降低单一因子风险
- 需要**足够的耐心和资金**（不被迫在低谷清盘）
- 需要**机制防止自己在黎明前放弃**

**最终答案**：
不是"要不要用价值因子"，而是"**如何在多因子框架下配置价值因子**"。永远保持15-40%的价值暴露，但结合其他因子分散风险，同时拉长投资周期。

### Search: Public filings

#### 2. Public filings

**公司根据其法律地位需要进行特定形式的备案，这些备案因司法管辖区而异**

**主要备案类型**:

#### A. 13F Filings
- **什么是13F**: 
  - 任何机构投资者需要向SEC提交的季度备案文件，详细说明其大型美国持仓
  - 投资顾问/对冲基金需要提交

- **包含内容**:
  - 所有美国持仓
  - CUSIP名称
  - 美元价值
  - 是否有投票权

- **不需要包括**:
  - 空头头寸或SSFs
  - 通常披露看涨和看跌期权（但不包括"已售出"的期权）
  - 例如对于 Anika Therapeutics，需要披露的头寸包括:
    - CUSIP NO 035255 10 8 COM
    - CUSIP NO 035255 90 8 CALL
    - CUSIP NO 035255 95 8 PUT

- **备案频率**: 季度性质，属于"快照"

#### B. N-PORT Filings
- **适用范围**:
  - 1940年投资公司法下注册的美国共同基金和ETF需要提交
  - 详细说明其在全球范围内的持仓
  - 每月的N-PORT报告在每月结束后60天公开

- **重要提示**: 投资顾问不提交N-PORT，只有其注册基金提交！

- **用途**: 
  - 是了解某些价值投资传奇人物（如Tweedy, Browne）在国际市场头寸的良好来源

## Part 3: VALUE TRAPS

### 📌 Q&A 4: 第25-27页的 Value Trap 想表达什么？

**问题**：第25-27页的 value trap 想表达什么？看不懂。

**回答（直白版）**：这三页其实在讲同一件事——**便宜不等于会涨**。  
很多股票看起来很便宜（低估值、高股息），但如果没有触发变化的因素，可能会长期“便宜下去”，这就是 value trap。

**第25页（简单例子）**：
- 市场价格 $P=50$，内在价值估计 $V=100$，表面看“很便宜”。
- 但你最终回报是否实现，取决于公司是否真的把现金流变好、把价值释放出来。
- 否则这 $V=100$ 可能只是纸面估计，股价不一定回归。

**第26页（催化剂）**：
- 讲的是“便宜股要涨，需要催化剂（Catalyst）”。
- 内生催化剂：回购、分拆、卖资产、管理层动作、产业内并购。
- 外生催化剂：盈利超预期（earnings surprise）等。
- 没有催化剂，便宜股容易一直便宜。

**第27页（实证表格）**：
- 把价值股按“盈利意外”分组后，结论很清楚：
  - **负盈利意外**的价值股，后续回报很差（典型 value trap）。
  - **正盈利意外**的价值股，后续回报显著更好。
- 所以不是“买低估值”就够了，还要看盈利方向是否改善。

**一句话总结**：  
第25-27页是在告诉你：**价值投资 = 低估值 + 盈利改善/催化剂**；只有低估值而没有改善，容易掉进 value trap。

### 📌 Q&A 5: 价值股为什么会“盈利不好”？这还算价值投资吗？

**问题**：价值股怎么还会出现盈利不好的情况？如果是价投，不应该盈利都很好吗？还是说这里的“价值”只是账面和市值比较，没有考虑商业模式和护城河？

**回答**：你理解得很到位。这里要区分两个“价值”的定义：

1. **量化里的 Value（因子定义）**  
  - 主要按低估值指标分组，比如高 $\text{BE}/\text{ME}$、低 $\text{P}/\text{B}$、低 $\text{P}/\text{E}$。  
  - 这是一种“统计上的便宜”，**不自动等于好公司**。

2. **基本面价值投资（Graham/Buffett 语境）**  
  - 要看商业模式、护城河、管理层、资本配置、现金流质量。  
  - 是“好公司 + 合理/便宜价格”，质量维度更强。

所以你说得对：课件这里的“价值股”更多是**因子口径的便宜股**，并没有先筛掉商业模式差或护城河弱的公司。  
这正是 value trap 出现的原因：

- 有些公司“便宜”是因为基本面正在恶化；
- 账面价值可能高，但资产回报率低、盈利下行、行业被颠覆；
- 结果就是“看起来便宜，但并不创造价值”。

**实务上怎么改进**：
- 用 **Value + Quality/Profitability** 联合筛选（比如高 $\text{BE}/\text{ME}$ 且高 ROIC、盈利稳定、低杠杆）；
- 再叠加催化剂（盈利改善、回购、分拆、行业出清）。

一句话：**低估值只是起点，不是结论**。真正的价投要把“便宜”和“好”同时满足。

### Value traps – 1: A simple example

**公式框架**:

| Assets | Earnings | Returns |
|--------|----------|---------|
| V=100, P=50 | E=10, D=10, P=50 | R = (50-10)/50 + 10/50 = 20% |
| No depreciation | Cost of capital = 10% | |

$$V = \frac{E}{0.10} = \frac{10}{0.10} = 100$$

$$R = \frac{150 - 50}{50} = 20\%$$

**关键概念**:
- **Efficiency**: Management dependent
- **Capital allocation**
- **Value**
- **Franchises**
- **Distributable cash flows**: Cash Dividends + Growth

### Value traps – 2: Catalysts

#### ① Endogenous (内生性催化剂):

1. **Large investors whose activism focuses market attention**  
   （大型投资者的激进主义使市场关注）

2. **Acquisitions by well informed firms in the same industry**  
   （同行业消息灵通公司的收购）

3. **Management**:
   - Share repurchases（股票回购）
   - Spin-offs, sales of assets, liquidation（分拆、资产出售、清算）

#### ② Exogenous (外生性催化剂):
- **Earnings surprises**（盈利意外）

### Value traps – 4: Where do your returns come from?

**回报率分解公式**:

$$R_{t,t+1} \equiv \frac{D_t}{V_t} + \frac{V_{t+1} - V_t}{V_t} = \frac{D_t}{V_t} + g_{t,t+1} + (1 + g_{t,t+1}) \times h_{t,t+1}$$

**三个组成部分**:

1. **"Dividend yield"（股息收益率）**: $\frac{D_t}{V_t}$
2. **"Dividend growth"（股息增长）**: $g_{t,t+1}$
3. **"Multiple expansion"（估值倍数扩张）**: $(1 + g_{t,t+1}) \times h_{t,t+1}$

### Investment Strategy Framework

根据回报来源的不同分类：

| Strategy | Primary Return Driver |
|----------|----------------------|
| **Value traps** | 仅依赖股息收益率，缺乏增长和估值扩张 |
| **Growth investing** | 主要依靠股息增长 |
| **Value investing** | 依靠估值倍数扩张 |
| **MODERN VALUE** | 综合考虑所有因素 |

## 总结

本讲座涵盖了价值投资中的三个重要主题：

1. **量化价值策略**: 理解价值溢价、构建量化价值基金的方法
2. **投资想法搜索**: 包括筛选方法、公开备案文件的使用
3. **价值陷阱**: 识别和避免价值陷阱，理解回报的真正来源

**关键启示**: 成功的价值投资不仅需要找到低估值的股票，还需要识别催化剂和避免价值陷阱。
