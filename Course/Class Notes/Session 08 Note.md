Value trap（价值陷阱）示例与股息率说明:
- 例子回顾：公司每期盈利 $10 并全部分红 $10（g=0），若折现率 r=10% 则理论价值 P = D / r = 10 / 0.10 = 100。但市场长期把该股以 $50 交易，此时按市场价格观察到的股息率为 10 / 50 = 20%。
- “市场价位上的股息率 = 10/50 = 20%” 的含义：这是一个观测变量，表示以当前市价投资，投资者每年能拿到的现金分红占投入的比例为 20%。它并不等同于“市场认为公司应该派发 20% 的盈利”，而是反映三种可能性中的一个或多个：
	- 市场对公司未来增长或分红的可持续性持怀疑态度（因此价格被压低）；
	- 公司面临较高风险或流动性折价，导致折价交易；
	- 当前分红可能是一次性或靠借债/卖资产支持，未必可持续。
- 投资含义：如果你相信分红可持续且倍数长期不会回升，那么你的回报确实主要来自该 20% 的现金流（而非资本利得）。但现实中应核查 FCF 覆盖分红、派息政策、偿债与资产出售来源等，以判断该股息率是否真实可获得或只是“幻象”。

实务检查清单（快速版）:
- 检查自由现金流（FCF）是否持续覆盖股息；
- 检查派息率与盈利趋势（是否用借债/卖资产支付股息）；
- 公司规模与流动性（小盘被长期贴折价的概率更高）；
- 行业与需求趋势（长期无增长风险）；
- 做情景分析：若股息被削减 25%/50%，IRR/净现值如何变化？
