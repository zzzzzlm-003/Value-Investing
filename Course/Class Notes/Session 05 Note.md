# Walmart 的案例分析

## ROIC 与估值倍数的关系
- **ROIC（投资资本回报率）与估值倍数的关系：**
  - ROIC 的提升通常表明公司资本使用效率的提高，这会降低投资风险，从而提升估值倍数（如市盈率）。
  - 对于农机行业，ROIC 的提升可能来自于技术创新（如精耕细作技术）或成本控制的优化。
- **Walmart 的案例：**
  - 在国际市场的扩张中，Walmart 遇到了文化和运营上的挑战，这可能导致了其 ROIC 的波动。

# 估值倍数压缩的原因

## 假设与逻辑
- **估值倍数压缩的原因：**
  - 折现率的变化通常由无风险利率和风险溢价的波动驱动。
  - 如果收益增长率保持稳定，但折现率上升，估值倍数会压缩。
- **均值回归的逻辑：**
  - 市场估值倍数的均值回归是基于历史数据的统计规律，反映了市场情绪的周期性变化。
  - 对于农机行业，估值倍数可能受到大宗商品价格周期的显著影响。

# Deere 的案例分析

## 本地化优势与行业特点
- **Deere 的本地化优势：**
  - Deere 的机械设备和服务网络具有显著的本地化特征，这使其能够更好地满足区域性需求。
  - 本地化的融资信息（如客户信用数据）帮助 Deere 降低了贷款风险。
- **行业特点：**
  - 农机行业的本地化依赖性较强，尤其是在地广人稀的地区。

## Midwest 的农业模式
- **Midwest 的农业模式：**
  - Midwest 地区人口密度低，农业生产以大规模机械化为主。
  - 经济规模效应使得大型农机企业在该地区具有显著优势。
- **本地化服务的挑战：**
  - 由于人口稀少，建立广泛的本地化服务网络成本较高，这进一步强化了对现有供应商的依赖。

## 周期性波动的影响

# ACO 和 CNH 的行业分析

## 行业周期性
- **ACO 和 CNH 的含义：**
  - ACO（AGCO Corporation）专注于农业设备的制造和分销。
  - CNH（CNH Industrial）是一家全球性的资本货物公司，旗下包括农业机械品牌如 Case IH 和 New Holland。
- **行业周期性：**
  - 农机行业与大宗商品（如玉米、小麦等）价格周期密切相关。
  - 当大宗商品价格上涨时，农民的收入增加，购买农机的需求也随之上升。
  - 关税政策可能通过影响大宗商品价格间接影响农机行业的需求。

# 证券化的定义与操作

## 定义与操作
- **证券化（Securitization）的定义：**
  - 证券化是将资产（如贷款、应收账款）打包成金融产品并出售给投资者的过程。
  - 对于 Deere 等公司，这通常涉及将农民的贷款打包成资产支持证券（ABS）。
- **Deere 的证券化操作：**
  - Deere 的金融服务部门将农机销售贷款打包成证券，并出售给其他金融机构。
  - 这种操作可以帮助公司回笼资金，同时将贷款风险转移给投资者。

## 优点与风险
- **优点：**
  - 提高资金流动性，降低公司持有的信用风险。
- **风险：**
  - 如果贷款违约率上升，可能导致投资者损失，从而影响公司的声誉。

# EPV（Earnings Power Value）计算过程

## 计算步骤
1. **调整收益：**
   - 从历史财务数据中剔除非经常性项目，计算可持续收益。
2. **计算折现率：**
   - 根据无风险利率和风险溢价确定折现率。
3. **估算价值：**
   - 使用公式 $EPV = Adjusted Earnings / Discount Rate$ 计算收益能力价值。

## 总结
- EPV 是一种基于公司当前收益能力的估值方法，适用于评估稳定业务的内在价值。
- 在计算过程中，需要特别关注收益的可持续性和折现率的合理性。

# 设备销售与融资业务模式

## 分析与问题
- **设备销售与融资的双重业务模式：**
  - 设备销售公司通常通过提供融资服务来促进销售。
  - 当销售疲软时，公司可能会向信用风险较高的客户提供贷款，以增加销售额。
- **潜在问题：**
  - 向信用风险较高的客户提供贷款可能导致坏账率上升。
  - 这种策略可能短期内提升销售，但长期来看会增加财务风险。

## 行业特点
- 写账（Write-off）率较低的公司通常具有更强的风险控制能力。
- 竞争激烈的市场中，企业的长期品牌价值较低，难以形成护城河。

## 问题与回答
- **为什么 GM 的写账率这么高？**
  - GM 所处的市场竞争激烈，客户忠诚度较低，导致信用风险较高。
  - 其融资业务可能更倾向于覆盖更广泛的客户群体，包括信用风险较高的客户。
- **是否是好生意？**
  - 写账率低表明公司在风险控制方面表现良好，但需要结合整体盈利能力和长期战略评估。
