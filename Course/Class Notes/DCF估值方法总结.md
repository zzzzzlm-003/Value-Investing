## DCF估值的正确逻辑

### 1. 核心原理
企业的价值 = 未来所有自由现金流的现值之和

$$\text{Enterprise Value} = \sum_{t=1}^{n} \frac{FCF_t}{(1+WACC)^t} + \frac{TV}{(1+WACC)^n}$$

### 2. 关键步骤

#### 第一步：预测FCF（Free Cash Flow）
预测未来每一期的自由现金流，通常包括：
- **预测期**：明确预测的5-13年（如图例中2026-2038年）
- **终值期**：预测期之后的永续价值

#### 第二步：确定折现率（WACC）
**折现率使用WACC（加权平均资本成本）**，不是简单的通胀率。

WACC的构成：
$$WACC = \frac{E}{E+D} \times R_e + \frac{D}{E+D} \times R_d \times (1-T)$$

其中：
- $R_e$ = 股权成本（已包含无风险利率、市场风险溢价、贝塔等）
- $R_d$ = 债务成本
- $E/(E+D)$ = 股权占比
- $D/(E+D)$ = 债务占比
- $T$ = 税率

**注意**：WACC本身已经反映了市场的通胀预期、风险溢价等因素。

### 股权成本（Cost of Equity, $R_e$）的计算

#### 重要概念：Return = Cost？

**CAPM确实算的是回报率（Return），但在估值中它就是成本（Cost）！**

这是同一件事的两个视角：

| 视角 | 名称 | 含义 |
|------|------|------|
| **投资者视角** | Required Return（要求回报率） | 我投资这家公司，要求获得的回报率 |
| **公司视角** | Cost of Equity（股权成本） | 公司使用股东资金的成本（机会成本） |

**为什么叫"成本"？**
1. **机会成本**：股东投资你的公司，就放弃了其他投资机会（如投资市场指数）
2. **期望补偿**：股东承担风险，要求相应的回报补偿
3. **融资代价**：如果公司项目回报 < Re，就是在毁灭股东价值

**实例理解**：
```
某科技公司股东要求的回报率（Re）= 12%
- 股东视角：我投$100，期望每年获得$12回报
- 公司视角：我使用股东的$100，每年"成本"是$12
- 如果公司新项目只能赚10%，股东会不满意（因为没达到12%的要求）
```

**关键**：股权成本没有"合同约定"（不像债务有固定利息），但它是**隐含的成本** —— 达不到这个回报，股价会下跌。

#### 方法1：CAPM模型（Capital Asset Pricing Model）**【最常用】**
$$R_e = R_f + \beta \times (R_m - R_f)$$

**各参数的确定：**

1. **无风险利率 $R_f$（Risk-free Rate）**
   - 通常使用：**10年期国债收益率**
   - 美国：10-Year Treasury Yield（如2.5% - 4%）
   - 中国：10年期国债收益率
   - 选择理由：匹配投资期限，流动性好

2. **贝塔系数 $\beta$（Beta）**
   
   **含义**：衡量股票相对于市场的**系统性风险**（波动性）
   - $\beta = 1$：与市场同步波动
   - $\beta > 1$：波动性大于市场（高风险，如科技股、小盘股）
   - $\beta < 1$：波动性小于市场（低风险，如公用事业、消费品）
   
   ---
   
   #### Beta的计算方法（线性回归）
   
   **原理**：Beta是股票收益率对市场收益率回归的**斜率**
   
   **回归模型**：
   $$R_{\text{stock},t} = \alpha + \beta \times R_{\text{market},t} + \epsilon_t$$
   
   其中：
   - $R_{\text{stock},t}$ = 股票在第t期的收益率
   - $R_{\text{market},t}$ = 市场指数在第t期的收益率
   - $\beta$ = 回归的斜率（我们要求的）
   - $\alpha$ = 截距（Jensen's Alpha）
   - $\epsilon_t$ = 残差（非系统性风险）
   
   **计算公式**：
   $$\beta = \frac{\text{Cov}(R_{\text{stock}}, R_{\text{market}})}{\text{Var}(R_{\text{market}})}$$
   
   或：
   $$\beta = \frac{\sum (R_{\text{stock}} - \bar{R}_{\text{stock}}) \times (R_{\text{market}} - \bar{R}_{\text{market}})}{\sum (R_{\text{market}} - \bar{R}_{\text{market}})^2}$$
   
   ---
   
   #### 计算步骤（实操）
   
   **第1步：收集历史数据**
   
   需要的数据：
   - **股票价格**：目标公司的历史股价
   - **市场指数**：
     - 美股：S&P 500
     - 港股：恒生指数
     - A股：沪深300或中证500
   - **时间跨度**：
     - **推荐：2-5年**（60个月度数据或250个周度数据）
     - 太短：数据不够，Beta不稳定
     - 太长：公司业务可能已改变
   - **数据频率**：
     - **月度数据**（最常用）：60个月
     - 周度数据：104-260周
     - 日度数据：不推荐（噪音太多）
   
   **第2步：计算收益率**
   
   对每一期（如每个月）：
   $$R_t = \frac{P_t - P_{t-1}}{P_{t-1}} = \frac{P_t}{P_{t-1}} - 1$$
   
   或用对数收益率：
   $$R_t = \ln\left(\frac{P_t}{P_{t-1}}\right)$$
   
   **第3步：回归计算Beta**
   
   用Excel或Python做线性回归：
   - X轴（自变量）：市场收益率
   - Y轴（因变量）：股票收益率
   - **回归斜率 = Beta**
   
   ---
   
   #### Excel操作示例
   
   **数据准备**：
   | 日期 | 股票价格 | 指数价格 | 股票收益率 | 指数收益率 |
   |------|---------|---------|-----------|-----------|
   | 2021-01 | 100 | 3000 | - | - |
   | 2021-02 | 105 | 3060 | 5.0% | 2.0% |
   | 2021-03 | 103 | 3090 | -1.9% | 0.98% |
   | ... | ... | ... | ... | ... |
   
   **计算方法**：
   1. 用公式计算收益率：`=(B3-B2)/B2`
   2. 使用Excel函数：
      ```excel
      =SLOPE(股票收益率范围, 指数收益率范围)
      ```
      例如：`=SLOPE(D2:D61, E2:E61)`
   
   3. 或使用回归分析：
      - 数据 → 数据分析 → 回归
      - Y范围：股票收益率
      - X范围：指数收益率
      - 查看"系数"中X Variable 1的值 = Beta
   
   ---
   
   #### Python代码示例
   
   ```python
   import pandas as pd
   import numpy as np
   from scipy import stats
   
   # 假设已有数据
   # df包含 'stock_price' 和 'market_index' 两列
   
   # 计算收益率
   df['stock_return'] = df['stock_price'].pct_change()
   df['market_return'] = df['market_index'].pct_change()
   
   # 去除第一行NaN
   df = df.dropna()
   
   # 方法1：用scipy做线性回归
   slope, intercept, r_value, p_value, std_err = stats.linregress(
       df['market_return'], 
       df['stock_return']
   )
   beta = slope
   
   # 方法2：用协方差公式
   cov_matrix = np.cov(df['stock_return'], df['market_return'])
   beta = cov_matrix[0,1] / cov_matrix[1,1]
   
   # 方法3：用pandas
   beta = df['stock_return'].cov(df['market_return']) / df['market_return'].var()
   
   print(f"Beta = {beta:.2f}")
   print(f"R-squared = {r_value**2:.2f}")  # 拟合优度
   ```
   
   ---
   
   #### 判断Beta的可靠性
   
   **查看回归统计指标**：
   
   1. **R²（拟合优度）**
      - 衡量市场能解释多少股票收益的波动
      - R² > 0.3：较可靠
      - R² < 0.2：Beta不稳定，考虑用行业Beta
   
   2. **t统计量 / p值**
      - 检验Beta是否显著不为0
      - p < 0.05：统计显著
      - p > 0.1：Beta可能不可靠
   
   3. **标准误差**
      - Beta的标准误差越小越好
      - 可以构建置信区间：$\beta \pm 2 \times SE$
   
   ---
   
   #### 数据来源 vs 自己计算
   
   | 方法 | 优点 | 缺点 | 适用场景 |
   |------|------|------|---------|
   | **Bloomberg查询** | 快速方便 | 黑盒，不知道用的什么参数 | 快速估算 |
   | **自己回归计算** | 透明，可调参数 | 需要数据和编程 | 正式估值报告 |
   | **行业平均Beta** | 处理单公司Beta不稳定 | 不够精确 | 小公司、数据不足 |
   
   **推荐实务做法**：
   1. 自己用5年月度数据回归计算Beta
   2. 与Bloomberg/Wind的值对比验证
   3. 如果差异大（>20%），检查数据和方法
   4. 如果R²很低，考虑用同行业可比公司的平均Beta
   
   ---
   
   #### 无杠杆Beta和有杠杆Beta
   
   **问题**：不同公司的资本结构不同，Beta会受杠杆影响
   
   **解决**：去杠杆化（Unlever）和再杠杆化（Relever）
   
   **公式**：
   $$\beta_{\text{levered}} = \beta_{\text{unlevered}} \times \left[1 + (1-T) \times \frac{D}{E}\right]$$
   
   反推无杠杆Beta：
   $$\beta_{\text{unlevered}} = \frac{\beta_{\text{levered}}}{1 + (1-T) \times \frac{D}{E}}$$
   
   **应用场景**：可比公司分析
   1. 找5-10家同行业可比公司
   2. 计算或查询每家的Beta（有杠杆）
   3. 去杠杆：用上面公式算出每家的 $\beta_{\text{unlevered}}$
   4. 求平均：行业平均无杠杆Beta
   5. 再杠杆：根据目标公司的D/E，算出其Beta
   
   **示例**：
   ```
   可比公司A：Beta = 1.3, D/E = 0.5, 税率 = 25%
   去杠杆：β_u = 1.3 / [1 + (1-0.25) × 0.5] = 1.3 / 1.375 = 0.95
   
   目标公司：D/E = 0.3, 税率 = 25%
   再杠杆：β_L = 0.95 × [1 + (1-0.25) × 0.3] = 0.95 × 1.225 = 1.16
   ```

3. **市场风险溢价 $R_m - R_f$（Market Risk Premium, MRP）**
   - 投资者要求的超过无风险利率的额外回报
   - 通常取值：
     - **美国市场：5% - 7%**（长期历史平均约6%）
     - **新兴市场：8% - 12%**（风险更高）
   - 数据来源：
     - Damodaran教授的年度更新（最权威）
     - 历史数据：标普500收益率 - 国债收益率
     - Ibbotson SBBI年鉴

**示例计算**：
```
假设分析一家美国科技公司：
- Rf = 3.5%（10年期美债）
- β = 1.3（科技股波动较大）
- MRP = 6.0%（美国市场历史均值）

Re = 3.5% + 1.3 × 6.0% = 3.5% + 7.8% = 11.3%
```

#### 方法2：股息增长模型（Gordon Growth Model / DDM）

**单阶段Gordon模型**：
$$R_e = \frac{D_1}{P_0} + g$$

其中：
- $D_1$ = 下一期预期股息
- $P_0$ = 当前股价
- $g$ = 股息永续增长率

**推导逻辑**：
如果股票的价值等于未来所有股息的现值：
$$P_0 = \frac{D_1}{1+R_e} + \frac{D_2}{(1+R_e)^2} + \frac{D_3}{(1+R_e)^3} + ...$$

假设股息以恒定速率g增长（$D_2 = D_1(1+g)$），可以简化为：
$$P_0 = \frac{D_1}{R_e - g}$$

反推：
$$R_e = \frac{D_1}{P_0} + g$$

**适用场景**：
- ✅ 成熟公司，股息稳定且可预测
- ✅ 红利股（如公用事业、REITs、银行）
- ✅ 派息率高，增长稳定
- ❌ 不派息的成长股（如科技公司）
- ❌ 派息不规律或波动大的公司

**示例**：
```
某公用事业公司：
- 当前股价 P₀ = $50
- 预期下年股息 D₁ = $3
- 历史股息增长率 g = 4%

Re = 3/50 + 0.04 = 6% + 4% = 10%
```

#### 两阶段股利折现模型（Two-Stage DDM）

**背景**：单阶段Gordon模型假设永续恒定增长，不适合处于高速增长期的公司。

**模型设计**：
- **第一阶段**：高速增长期（如5-10年），增长率 $g_1$
- **第二阶段**：稳定增长期（永续），增长率 $g_2$（接近GDP增长）

**公式**：
$$P_0 = \sum_{t=1}^{n} \frac{D_0 \times (1+g_1)^t}{(1+R_e)^t} + \frac{P_n}{(1+R_e)^n}$$

其中第二阶段的价值（终值）：
$$P_n = \frac{D_{n+1}}{R_e - g_2} = \frac{D_n \times (1+g_2)}{R_e - g_2}$$

**示例**：
```
某零售公司：
- 当前股息 D₀ = $2
- 前5年高速增长：g₁ = 15%
- 之后永续增长：g₂ = 3%
- 股权成本 Re = 12%

第一阶段（1-5年）现值：
Year 1: 2×1.15/(1.12)¹ = 2.05
Year 2: 2×1.15²/(1.12)² = 2.11
Year 3: 2×1.15³/(1.12)³ = 2.16
Year 4: 2×1.15⁴/(1.12)⁴ = 2.22
Year 5: 2×1.15⁵/(1.12)⁵ = 2.28
小计 ≈ $10.82

第二阶段（终值）：
D₆ = 2 × 1.15⁵ × 1.03 = 4.14
P₅ = 4.14 / (0.12 - 0.03) = 46.0
现值 = 46.0 / (1.12)⁵ = $26.1

总价值 = 10.82 + 26.1 = $36.92
```

**何时使用两阶段模型**：
- 公司正在从高速增长向成熟转型
- 预期派息政策会改变（如从低派息到高派息）
- 更灵活，适用范围更广

---

#### Gordon模型在DCF中的应用（重要区别！）

**关键区别**：虽然都叫"Gordon模型"，但在DCF估值中的用途不同

| 用途 | 场景 | 公式 | 用的变量 |
|------|------|------|---------|
| **计算股权成本** | 方法2（上面） | $R_e = \frac{D_1}{P_0} + g$ | 股息D，股价P |
| **计算DCF终值** | 第四步（下面） | $TV = \frac{FCF_n(1+g)}{WACC-g}$ | 自由现金流FCF |

**DCF终值的Gordon公式**：
$$TV = \frac{FCF_n \times (1+g)}{WACC - g}$$

**重要**：
- ✅ 用的是**FCF（自由现金流）**，不是股利
- ✅ 适用于**任何公司**，无论是否派息
- ✅ 折现率用**WACC**，不是Re
- 永续增长率g通常为2-3%（接近长期GDP/通胀）

**为什么不用股利？**
因为DCF估值的是**企业价值（EV）**，而不是股权价值。FCF是企业产生的总现金流，归债权人和股东所有。

**总结对比**：
```
Gordon计算Re（股息模型）：
- 只看派给股东的股息
- 适用于红利股
- 算的是股权成本

Gordon计算TV（DCF终值）：
- 看企业的全部自由现金流
- 适用于所有公司
- 算的是企业终值
```

较复杂，实务中较少使用。

### 债务成本（Cost of Debt, $R_d$）的计算

#### 方法1：利息覆盖率法**【最直接】**
$$R_d = \frac{\text{利息支出（Interest Expense）}}{\text{总债务（Total Debt）}}$$

**步骤**：
1. 从财报获取：
   - **利息支出**：利润表中的"财务费用-利息支出"或"Interest Expense"
   - **总债务**：资产负债表中的"短期借款+长期借款+应付债券"
   
2. 计算当期实际利率：
   $$R_d = \frac{\text{年度利息支出}}{\text{平均债务余额}}$$

3. **税盾调整（Tax Shield）**：
   $$R_{d,\text{after-tax}} = R_d \times (1 - T)$$
   
   因为利息支出可以抵税，实际成本更低

**什么叫"利息支出可以抵税"？**

**原理**：在计算企业所得税时，**利息支出可以从税前利润中扣除**，减少应税收入。

**对比示例**（假设税率25%）：

| 项目 | 无债务公司 | 有债务公司 |
|------|-----------|-----------|
| 税前利润（EBIT） | $1,000 | $1,000 |
| **利息支出** | $0 | **$200** |
| **应税收入（EBT）** | $1,000 | **$800** |
| 所得税（25%） | $250 | **$200** |
| 税后净利润 | $750 | $600 |
| **实际利息成本** | - | **$200 - $50 = $150** |

**关键**：
- 有债务公司支付了$200利息
- 但税收从$250降到$200，**节省了$50**
- 实际成本 = $200 - $50 = $150
- **有效利率** = 150/2000 = 7.5%（而不是10%）

**公式推导**：
```
原始债务成本：Rd = 10%（支付利息200/债务2000）
节税金额：利息 × 税率 = 200 × 25% = 50
实际成本：200 - 50 = 150

有效率 = 150/2000 = 7.5% = 10% × (1-25%)
```

**为什么股权成本不能抵税？**
- **股利不能抵税**：分红是税后利润分配，不能在税前扣除
- 利息是**费用**（在利润表上），股利是**分配**（在资产负债表上）
- 这就是**债务的税收优势**（Tax Advantage of Debt）

**会计处理**：
```
利润表：
营业收入         $5,000
营业成本         $3,000
营业利润（EBIT） $2,000
利息支出         $ 200  ← 在这里扣除！
税前利润（EBT）  $1,800
所得税（25%）    $ 450  ← 基于扣除利息后的金额
净利润          $1,350
```

如果没有利息支出：
```
所得税 = $2,000 × 25% = $500
有利息支出：
所得税 = $1,800 × 25% = $450
节省 = $50 = $200 × 25%（利息×税率）
```

**示例**：
```
某公司2025年数据：
- 利息支出 = $50M
- 总债务 = $800M
- 税率 = 25%

税前债务成本：Rd = 50/800 = 6.25%
税后债务成本：Rd(after-tax) = 6.25% × (1-0.25) = 4.69%
```

#### 方法2：到期收益率法（Yield to Maturity, YTM）
如果公司有公开交易的债券：
- 使用**债券的到期收益率（YTM）**作为债务成本
- 数据来源：Bloomberg, Wind, 债券市场价格

**优点**：反映当前市场要求的回报率  
**缺点**：需要有流动性好的公开债券

#### 方法3：合成评级法（Synthetic Rating）
如果没有债券评级，根据财务指标估算：

1. **计算利息覆盖倍数**：
   $$\text{Interest Coverage Ratio} = \frac{\text{EBIT}}{\text{利息支出}}$$

2. **对应信用评级**：
   | 利息覆盖倍数 | 信用评级 | 债务成本估计 |
   |------------|---------|------------|
   | > 8.5x | AAA | Rf + 0.7% |
   | 6.5 - 8.5x | AA | Rf + 1.0% |
   | 5.5 - 6.5x | A+ | Rf + 1.3% |
   | 4.3 - 5.5x | A | Rf + 1.5% |
   | 3.0 - 4.3x | BBB | Rf + 2.0% |
   | 2.5 - 3.0x | BB | Rf + 3.5% |
   | < 2.5x | B或更低 | Rf + 5%+ |

3. **加上违约利差（Default Spread）**：
   $$R_d = R_f + \text{Default Spread}$$

---

### WACC完整计算示例

**假设某公司情况**：
- 市值（E）= $5,000M
- 债务（D）= $2,000M
- 税率（T）= 25%

**股权成本**：
- Rf = 3.5%
- β = 1.2
- MRP = 6%
- Re = 3.5% + 1.2 × 6% = **10.7%**

**债务成本**：
- 利息支出 = $120M
- Rd(税前) = 120/2000 = 6%
- Rd(税后) = 6% × (1-0.25) = **4.5%**

**WACC计算**：
$$WACC = \frac{5000}{7000} \times 10.7\% + \frac{2000}{7000} \times 4.5\%$$
$$WACC = 0.714 \times 10.7\% + 0.286 \times 4.5\%$$
$$WACC = 7.64\% + 1.29\% = 8.93\% \approx 9\%$$

---

### 实务中的注意事项

1. **使用市场价值而非账面价值**
   - E和D都应该用市场价值（Market Value）
   - E = 股价 × 流通股数
   - D = 债务的市场价值（如无公开交易，可用账面价值近似）

2. **Beta的选择**
   - 优先使用**2-5年**的历史数据
   - 考虑使用行业平均Beta（去杠杆化后）

3. **地区调整**
   - 新兴市场需要加**国家风险溢价（Country Risk Premium）**：
   $$R_e = R_f + \beta \times (MRP + CRP)$$

4. **定期更新**
   - 无风险利率随市场变化
   - Beta每年可能变化
   - 资本结构调整时需重新计算

#### 第三步：计算折现因子（Discount Factor）
每一期的折现因子：
$$\text{Factor}_t = \frac{1}{(1+WACC)^t}$$

从图例可见：
- 2026年（第1年）：Factor = 0.89 = 1/(1+0.12)^1
- 2027年（第2年）：Factor = 0.80 = 1/(1+0.12)^2
- 以此类推...

#### 第四步：计算终值（Terminal Value）
**Multiple的真正作用在这里**！

终值有两种计算方法：

**方法1：永续增长模型（Gordon Growth Model）**
$$TV = \frac{FCF_n \times (1+g)}{WACC - g}$$

**方法2：退出倍数法（Exit Multiple / Exit Valuation）**
$$TV = FCF_n \times \text{Multiple}$$

---

### Multiple详解（倍数法Terminal Value）

#### 什么叫Multiple？

**Multiple（倍数）** = 用某个财务指标的倍数来估值

**原理**：如果你知道某个指标值，乘以合理的倍数，就能估出企业价值。

**常见的Multiple类型**：

| Multiple | 公式 | 含义 | 用途 |
|----------|------|------|------|
| **P/E倍数** | 股价 / 每股收益EPS | 每赚1块钱，值几块钱 | 股权估值 |
| **EV/EBITDA** | 企业价值 / 息税前利润 | 每赚1块息税前利润，值几块钱 | 企业估值 |
| **EV/Revenue** | 企业价值 / 收入 | 每块收入，值几块钱 | 初创公司 |
| **EV/FCF** | 企业价值 / 自由现金流 | 每块FCF，值几块钱 | **DCF终值** |

---

#### DCF中的Multiple（关键！）

在Terminal Value中用的Multiple，通常是 **EV/FCF倍数**：

$$TV = FCF_n \times \text{EV/FCF Multiple}$$

**理解**：
- 第n年的FCF，乘以某个倍数
- 这个倍数反映"市场愿意给这样的现金流付多少钱"

**从Cellebrite案例**：
```
2038年 FCF = $1,403.6M
Multiple = 11.1
Terminal Value = 1,403.6 × 11.1 = $15,580M（未折现）

意思是：市场愿意用11.1倍的EV/FCF来给这家公司估值
```

---

#### Multiple和Gordon公式的关系

**关键发现**：这两种方法能算出同样的Multiple！

从Gordon公式：
$$TV = \frac{FCF_n(1+g)}{WACC - g}$$

整理一下：
$$TV = FCF_n \times \frac{1+g}{WACC - g}$$

看！括号里的 $\frac{1+g}{WACC - g}$ 就是**隐含的Multiple**！

**数值例子**：
```
WACC = 12%, g = 3%

Multiple = (1 + 0.03) / (0.12 - 0.03)
        = 1.03 / 0.09
        = 11.4

所以用Gordon：
TV = FCF × 11.4

同样的倍数！
```

**Cellebrite的验证**：
```
Multiple = 11.1（给定）
反推WACC和g：
11.1 = (1 + g) / (WACC - g)

如果WACC = 12%, g = 3%：
Multiple = 1.03 / 0.09 = 11.4 ≈ 11.1 ✅（接近！差异可能由四舍五入）
```

---

#### 两种方法的区别和选择

| 方面 | Gordon公式 | Multiple法 |
|------|-----------|----------|
| **输入** | WACC, g, FCF | Multiple, FCF |
| **逻辑** | 基于增长和成本 | 基于市场可比 |
| **适用** | 参数透明 | 数据容易获得 |
| **计算** | 更严格 | 更快速 |
| **误差来源** | WACC/g设定 | Multiple选择 |

**实务中通常两个都算**：
1. 用Gordon算出理论Terminal Value
2. 用可比公司的Multiple验证
3. 如果差异大，检查参数设定

---

#### 怎么选择Multiple？

**方法1：行业可比法**（最常用）

找同行业的可比公司，看他们现在的EV/FCF倍数：

```
例：科技公司估值
1. 找5个可比上市公司（如微软、谷歌等）
2. 查询它们当前的 EV / 去年FCF 倍数
3. 算平均值，如12倍
4. 假设我们估值的公司也用12倍
5. TV = FCF₁₃ × 12
```

**注意**：
- 选择真正可比的公司（行业、规模、增长率相似）
- 可能需要调整（我们的公司成长性更好，用13倍；更差，用11倍）
- 用当前还是未来Multiple？（通常用未来，因为估值是前瞻的）

**方法2：从Gordon推导**

如果有WACC和g的估计，直接算：
$$\text{Multiple} = \frac{1+g}{WACC-g}$$

```
我们的估计：WACC = 10%, g = 3%

Multiple = 1.03 / (0.10 - 0.03) = 1.03 / 0.07 = 14.7
```

**方法3：敏感性分析**

因为Multiple很敏感，通常做一个范围：

```
行业平均Multiple：12倍
我们的范围：
- 悲观：10倍（增长或质量差）
- 基准：12倍（行业平均）
- 乐观：15倍（增长或质量好）

3种场景分别算TV，看对估值的影响
```

---

#### Multiple的陷阱

**1. 用的指标要一致**
```
❌ 错：EV/EBITDA Multiple = 15，然后用FCF × 15
✅ 对：EV/FCF Multiple = 12，然后用FCF × 12
```

**2. 时间要一致**
```
❌ 错：用今年（2026）的可比公司Multiple，来折现2038年的FCF
✅ 对：应该估计2038年的Multiple（通常会更低）
```

**3. Multiple会变化**
```
高增长公司 → 高Multiple（市场愿意付高价）
成熟公司 → 低Multiple（增长慢）

在Terminal Value中，应该假设Multiple会回归到
稳定期的水平（通常比现在低）
```

---

#### 实例：Multiple和Gordon的一致性

**Cellebrite案例反推**：

已知：
- 2038年FCF = $1,403.6M
- Multiple = 11.1
- WACC = 12%
- g = 3%

验证Multiple是否与Gordon一致：
```
Gordon Multiple = (1 + 0.03) / (0.12 - 0.03)
                = 1.03 / 0.09
                = 11.44

实际Multiple = 11.1

差异 = (11.44 - 11.1) / 11.44 = 3%

非常接近！说明数据是一致的。
（小差异可能由于四舍五入或微调的g值）
```

### Gordon模型推导（重要！理解终值的本质）

#### 为什么Terminal Value用这个公式？

**问题**：第n年之后，还有无穷多年的FCF，怎么折现？

**解决**：假设从n+1年开始，FCF以恒定速率g永续增长，用公式一次性算出它们的现值。

**完整推导**：

**第一步**：第n+1年及之后的所有FCF
$$FCF_{n+1}, FCF_{n+2}, FCF_{n+3}, ...$$
$$\text{其中} \quad FCF_{n+1} = FCF_n \times (1+g)$$
$$FCF_{n+2} = FCF_n \times (1+g)^2$$
$$\text{以此类推}$$

**第二步**：这些现金流在第n期末的现值（这就是Terminal Value）
$$TV_n = \frac{FCF_{n+1}}{WACC} + \frac{FCF_{n+2}}{WACC^2} + \frac{FCF_{n+3}}{WACC^3} + ...$$

代入 $FCF_{n+t} = FCF_n \times (1+g)^t$：
$$TV_n = \frac{FCF_n(1+g)}{WACC} + \frac{FCF_n(1+g)^2}{WACC^2} + \frac{FCF_n(1+g)^3}{WACC^3} + ...$$

提取公因子 $FCF_n(1+g)$：
$$TV_n = FCF_n(1+g) \times \left[\frac{1}{WACC} + \frac{1+g}{WACC^2} + \frac{(1+g)^2}{WACC^3} + ...\right]$$

**第三步**：求和（这是关键！）

方括号内是一个**等比级数**：
- 首项 $a = \frac{1}{WACC}$
- 公比 $r = \frac{1+g}{WACC}$（因为每项都乘以 $\frac{1+g}{WACC}$）

当 $r < 1$（即 $WACC > g$）时，等比级数求和：
$$S = \frac{a}{1-r} = \frac{\frac{1}{WACC}}{1 - \frac{1+g}{WACC}} = \frac{\frac{1}{WACC}}{\frac{WACC-(1+g)}{WACC}} = \frac{1}{WACC-1-g}$$

等等，让我重新算：

$$S = \frac{\frac{1}{WACC}}{1 - \frac{1+g}{WACC}}$$

分母：$1 - \frac{1+g}{WACC} = \frac{WACC - (1+g)}{WACC} = \frac{WACC - 1 - g}{WACC}$

所以：
$$S = \frac{\frac{1}{WACC}}{\frac{WACC-1-g}{WACC}} = \frac{1}{WACC-1-g}$$

不对，这还是有问题。让我用另一个方法：

**用替代法**：设 $x = \frac{1+g}{WACC}$，则 $\frac{1}{WACC} = \frac{x}{1+g}$

$$S = \frac{1}{WACC} + \frac{1+g}{WACC^2} + \frac{(1+g)^2}{WACC^3} + ...$$

$$= \frac{1}{WACC}[1 + x + x^2 + ...]$$

$$= \frac{1}{WACC} \times \frac{1}{1-x}$$（等比级数求和）

$$= \frac{1}{WACC} \times \frac{1}{1 - \frac{1+g}{WACC}}$$

$$= \frac{1}{WACC} \times \frac{WACC}{WACC-(1+g)}$$

$$= \frac{1}{WACC-1-g}$$

还是有1...算了，用标准形式：

$$S = \frac{1}{WACC} \times \frac{1}{1-\frac{1+g}{WACC}} = \frac{1}{\WACC - (1+g)} = \frac{1}{WACC - g - 1}$$

这还是不对。让我直接用标准推导：

**标准推导**（从Gordon股利模型出发）：

股票价值 = 所有未来股利的现值
$$P = D_1 + \frac{D_2}{1+R} + \frac{D_3}{(1+R)^2} + ...$$

如果股利以恒定速率g增长，$D_t = D_1(1+g)^{t-1}$：
$$P = \frac{D_1}{1+R} + \frac{D_1(1+g)}{(1+R)^2} + \frac{D_1(1+g)^2}{(1+R)^3} + ...$$

$$= D_1 \left[\frac{1}{1+R} + \frac{1+g}{(1+R)^2} + \frac{(1+g)^2}{(1+R)^3} + ...\right]$$

$$= \frac{D_1}{1+R} \left[1 + \frac{1+g}{1+R} + \left(\frac{1+g}{1+R}\right)^2 + ...\right]$$

这是首项为1，公比为 $\frac{1+g}{1+R}$ 的等比级数。当 $R > g$ 时：

$$\sum = \frac{1}{1-\frac{1+g}{1+R}} = \frac{1+R}{1+R-(1+g)} = \frac{1+R}{R-g}$$

所以：
$$P = \frac{D_1}{1+R} \times \frac{1+R}{R-g} = \frac{D_1}{R-g}$$

**用于终值**：类似地，从第n年到永远的FCF现值：
$$TV_n = \frac{FCF_{n+1}}{WACC-g} = \frac{FCF_n \times (1+g)}{WACC-g}$$

**第四步**：这个TV_n是在第n期末的价值，要折现到现在（第0期）：
$$PV(TV) = \frac{TV_n}{(1+WACC)^n}$$

---

### 直观理解

**为什么分母是 $WACC - g$？**

想象：
- FCF年年增长g%
- 投资者要求WACC%的回报
- 增长越快（g越大），企业价值越高
- 如果g接近WACC，分母接近0，价值趋于无穷（不现实）
- 所以**必须WACC > g**，否则模型无效

**数值例子**：
```
第n年 FCF = $100
永续增长率 g = 3%
WACC = 12%

Terminal Value（第n期末）
= $100 × 1.03 / (0.12 - 0.03)
= $103 / 0.09
= $1,144

理解：
- 接下来每年FCF为 $103, $106, $109, ...（3%增长）
- 用WACC 12%折现这些无穷现金流
- 现值 = $1,144

如果是退出倍数法：
Terminal Value = $100 × 11.44 = $1,144
（这里倍数11.44对应于 (1+g)/(WACC-g) = 1.03/0.09）
```

---

### 关键条件：WACC > g

这是Terminal Value模型成立的**必要条件**！

---

#### 常见误解："WACC > g，成本比增长多？"

**不对！这是概念混淆。** WACC和g不是同一维度的对比：

| 概念 | 含义 | 典型值 | 性质 |
|------|------|--------|------|
| **WACC** | 投资者要求的**回报率** | 8-12% | **固定**的资本成本 |
| **g** | 公司永续**增长率** | 2-3% | **公司特定**的长期增长 |

**它们不是相减的关系！**

---

#### 直观理解（用投资角度）

**假设你是投资者**：

```
场景1：普通投资
我要求10%的年回报 (WACC = 10%)
这家公司每年增长3% (g = 3%)

合理吗？✅ 绝对合理！
- 公司增长 < 我的要求回报
- 公司通过"赚钱能力"来满足我的回报要求
- 3%增长 + 7%的其他收益（如派息、回购、利润复合）= 我的10%要求
```

**假设反过来**：
```
如果我要求10%回报，但公司只有1%增长
- 公司明显不够好
- 不能满足我的要求
- 我会抛售股票，股价下跌
- 直到PE倍数降低到让回报达到10%为止
```

---

#### 公式角度（为什么必须WACC > g）

**从Gordon公式看**：
$$TV = \frac{FCF_n(1+g)}{WACC - g}$$

这是一个**估值乘数**。让我们看看g的不同取值：

| g值 | WACC-g | TV的倍数 | 含义 |
|-----|---------|---------|------|
| 2% | 10% | 10.3倍 | 正常 |
| 5% | 7% | 15倍 | g越大，倍数越高 |
| 8% | 4% | 27倍 | 高增长，高倍数 |
| 9% | 3% | 34倍 | 接近WACC，倍数爆炸 |
| **10%** | **2%** | **51倍** | 极端，不现实 |
| **11%** | **1%** | **101倍** | 完全不合理 |
| **12%** | **0** | **∞** | 数学上无穷！ |
| **13%** | **-1%** | **负数** | 逻辑矛盾！ |

**看出来了吗？** g一旦接近WACC，估值倍数会爆炸，说明模型假设有问题。

---

#### 为什么g通常只有2-3%？

**永续增长率g的含义**：公司未来**永久维持**的增长率

这必须满足：
1. **不能超过全球GDP增长**（通常2-3%）
   - 长期来看，一家公司不可能持续增长快于经济
   - 否则最后会比整个经济还大（荒谬）

2. **不能超过人口+生产率增长**
   - 这是长期经济增长的自然上限

3. **不能建立在短期优势上**
   - Terminal Value用的是永续（forever）
   - 短期的5-10年高增长不能用在Terminal Value

**例子**：
```
苹果现在增长20%/年，很厉害
但在Terminal Value中，不能用20%作为g
因为：
- 不能永远增长20%（太高了）
- 最终会成熟化，回到3-4%增长
- 所以Terminal Value用3-4%的g

而前13年（预测期）可以用高增长，
然后过渡到稳定增长
```

---

#### 正确的关系理解

**用现实语言翻译公式**：

$$TV = \frac{FCF_n(1+g)}{WACC - g}$$

意思是：

> "一家公司最后一年赚了FCF_n的现金  
> 之后每年增长g%  
> 投资者要求WACC%的回报  
> 那么这笔永续现金流值多少钱？  
> 答案 = FCF × (1+g) / (WACC - g)"

**WACC - g 的真正含义**：

```
WACC - g = 实际收益率（超过增长的部分）

例子：
- WACC = 10%（我要求的回报）
- g = 3%（公司增长）
- WACC - g = 7%（超额收益）

这7%来自哪里？
- 利润增长 3%
- 派息、回购等 4%
- 合计 = 我的10%要求
```

**如果g = WACC**：
```
WACC - g = 0
不能有超额收益
分母为0，价值无穷大

现实中这不可能，说明预设有误：
- 要么g设得太高
- 要么WACC设得太低
```

---

#### 实务检查清单

使用Gordon公式时，检查：

- [ ] **g是否合理？**
  - g通常2-4%（接近GDP增长）
  - 快速增长公司 ≤ 3%
  - 成熟稳定公司 = 2-2.5%

- [ ] **WACC > g吗？**
  - 通常WACC 8-12%，g 2-3%
  - WACC - g 应该至少 3-5%

- [ ] **模型用对了吗？**
  - 高增长期（5-10年）→ 用实际预测
  - 稳定期（之后永续）→ 才用g的Gordon
  - 不能把高增长g用在Terminal Value

---

#### 两阶段的做法（最实用）

正因为这个问题，实务中用**两阶段估值**更合理：

```
0-13年：预测期（用具体预测的高增长）
        如苹果这几年8-10%增长

13年后：永续期（用低增长率g）
        如3%永续增长
        TV = FCF₁₃ × 1.03 / (10% - 3%)
```

**两个g完全不同**：
- 预测期内：逐年不同的增长率（可能15%, 12%, 8%, 5%, 3%...递减）
- Terminal Value：永续恒定的低增长率（通常2-3%）

这样既能体现公司的短期机会，又不会高估长期价值。

#### 第五步：汇总计算企业价值
$$\text{PV (Present Value)} = \sum \text{各期折现后的FCF} + \text{终值的现值}$$

从图例：
- 各期Value相加 = 147.1 + 162.1 + ... + 321.7 = 约2,916
- 终值现值 = 3,574.1（这是TV折现后的值）
- **总PV = 6,490.7**
- **EV (Enterprise Value) = 3,718.1**（可能扣除了现金或加上了债务）

### 3. 关键理解点

| 概念 | 说明 |
|------|------|
| **WACC vs 通胀** | WACC是资本成本，已包含通胀预期，不需要单独考虑通胀 |
| **Multiple的位置** | Multiple用于计算**终值**，不是用于最终价格 |
| **两阶段折现** | 预测期的FCF逐年折现 + 终值的一次性折现 |
| **成长率g** | 终值的永续增长率，通常为2-3%（接近长期GDP增长） |

---

## Cellebrite案例数据（参考图片）

**公司**：Cellebrite (CLBT: Nasdaq)  
**估值日期**：2026年1月  
**估值参数**：
- WACC = 12%
- 永续增长率 = 3.0%
- 退出倍数 = 11.1

**计算结果**：

## 总结

### DCF的完整流程
```
预测FCF → 用WACC折现 → 计算终值（用Multiple或永续增长） → 终值也要折现 → 汇总得到企业价值
```

### 三个关键公式
1. **现值公式**：$PV = \frac{FCF}{(1+WACC)^t}$
2. **终值公式**：$TV = \frac{FCF_n \times (1+g)}{WACC - g}$ 或 $TV = FCF_n \times Multiple$
3. **企业价值**：$EV = \sum PV(FCF) + PV(TV)$

## 补充问答：Spontaneous Liabilities 是什么

### 定义
**Spontaneous Liabilities（自发性负债）**是指：

> 随着公司经营规模（尤其是收入）自然增长而自动增长的负债，
> 不需要公司主动去融资谈判。

最典型的是：
- **应付账款（Accounts Payable）**
- **应计费用（Accrued Expenses）**
- **应付税费（Taxes Payable）**

它们通常不计息，属于“免费”或低成本资金来源。

---

### 直观理解
公司先拿到供应商货物，之后再付款：

```
先卖货收现金 → 过一段时间才付供应商
中间这段时间，相当于供应商在给公司“垫资”
```

这笔“垫资”就是自发性负债带来的营运资金支持。

---

### 在DCF/FCF里的影响
FCF里有一项叫营运资本变动：

$$FCF = NOPAT + D\&A - CAPEX - \Delta NWC$$

而：

$$NWC = Operating\ Current\ Assets - Operating\ Current\ Liabilities$$

自发性负债属于 `Operating Current Liabilities`。  
当自发性负债上升时，$NWC$ 下降（或增幅变小），因此：

- 对现金流是**正贡献**（少占用现金）
- 会**提高FCF**

---

### 一个小例子

假设今年收入增长，导致：
- 应收账款 +20
- 存货 +15
- 应付账款 +18（自发性负债增加）

则：
$$\Delta NWC = 20 + 15 - 18 = 17$$

FCF会减去17。  
如果没有这18的应付账款增长，$\Delta NWC$会是35，FCF更差。

所以自发性负债本质上在“缓冲”营运资金占用。

---

### 和有息债务的区别

| 项目 | 自发性负债 | 有息债务 |
|------|-----------|---------|
| 来源 | 经营过程自然形成 | 主动融资（银行/债券） |
| 成本 | 通常不计息 | 需支付利息 |
| 是否进WACC债务端 | 通常不作为D | 是（Debt） |
| 在模型中的位置 | 营运资本（NWC） | 资本结构（WACC） |

一句话：  
**Spontaneous Liabilities是经营里的“自动融资”，主要影响$\Delta NWC$和FCF，不是WACC里的有息债。**
