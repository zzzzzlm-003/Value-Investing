## Part C Q6 / Q7 草稿

### Q6 Asset Value

- Inventories：LIFO→FIFO，加回 2,721
- PPE：定性，土地/建筑/设备有低估可能
- FS equity：审慎看能否覆盖压力损失，母公司无自动连带
- Brand：Interbrand 8.8B
- Product：P = R&D_25 + 0.8*24 + 0.6*23 + 0.4*22 + 0.2*21 ≈ 6,531

### Q7 EPV

- EBIT = 5145+372+414 = 5931
- 增长调整：R&D 1004.7 + Brand 762.9 = 1767.6
- Adj Op Income = 7698.6
- NOPAT ≈ 6172.4（税率 ~19.8%）
- EPV = 6172.4 / 0.07 ≈ 88.2B
