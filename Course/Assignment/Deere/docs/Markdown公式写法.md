# Markdown 里公式怎么打、为什么显示不出来

## 1. 两种常用写法

| 类型 | 写法一（常用） | 写法二 |
|------|----------------|--------|
| **行内公式** | `$...$` | `\(...\)` |
| **独立一行公式** | `$$...$$` | `\[...\]` |

**示例：**

- 行内：`税率 $t = 1020/5145 \approx 19.8\%$` → 税率 $t = 1020/5145 \approx 19.8\%$
- 独立一行：
  ```markdown
  $$EPV = \frac{NOPAT}{WACC} = \frac{6172.4}{0.07} = 88177$$
  ```

**常用 LaTeX：**

- 乘号：`\times`  
- 分数：`\frac{分子}{分母}`  
- 约等于：`\approx`  
- 下标：`P_{prod}`  
- 上标：`x^2`  
- 文字：`\text{Income before tax}`  
- 百分号：`19.8\%`（`\%` 才显示为 %）

---

## 2. 为什么“显示不出来”？

**公式能不能显示，取决于你用什么打开/渲染这份 .md：**

| 环境 | 是否支持公式 |
|------|----------------|
| **GitHub / GitLab 网页** | 不支持，只看到原始 `$...$` 或 `\[...\]` |
| **VS Code / Cursor 默认预览** | 多数默认不支持，只看到源码 |
| **VS Code + 插件** | 装 **Markdown All in One** 或 **Markdown+Math** 后，用 `$` / `$$` 一般能显示 |
| **Typora** | 支持 `$` 和 `$$` |
| **导出成 PDF** | 用 **Pandoc** 或 **Typora 导出** 并开启数学支持，公式会正常显示 |

所以：**不是公式写错了，而是当前预览/网站不支持数学公式。**

---

## 3. 想看到公式时怎么做？

1. **在 Cursor/VS Code 里看**  
   装插件：**Markdown All in One** 或 **Markdown+Math**，再用预览打开该 .md，公式一般就能渲染。

2. **要交 PDF**  
   - 用 **Typora** 打开 .md，菜单里导出为 PDF；或  
   - 用 **Pandoc**：  
     `pandoc Deere-Homework-提交版.md -o output.pdf --mathjax`  
   这样公式会按 LaTeX 渲染进 PDF。

3. **放上 GitHub**  
   GitHub 的 .md 不渲染公式，会看到原始 `$...$`。若必须在线看公式，可先把 .md 转成 PDF 再上传，或用支持公式的文档站。
