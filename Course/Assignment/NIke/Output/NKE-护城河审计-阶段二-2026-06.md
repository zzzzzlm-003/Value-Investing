# NKE 护城河审计（阶段二）

> 数据来源：Nike FY2025 10-K + FY2026 Q2/Q3 10-Q；竞品财报（On Holdings Q1 2026、Deckers FY2026、New Balance FY2025、adidas FY2025、Anta FY2025）；StockX 2025 年度报告；公开市场份额数据（Euromonitor/SGI）。完成日期：2026/6/16。
> 本轮任务：**不做买卖结论**，只给出各品类的护城河宽度评分（widening / stable / eroding）+ 证据 + bull/base/bear 护城河情景 → 为阶段三估值提供参数。

## 0. 框架先说清楚

**Nike 护城河 = Greenwald 消费特许权**：不是"你走不了"（切换成本），而是"你不想走、还爱买"——由 **品牌 IP + 习惯性复购 + 规模经济** 构成。关键性质：比 Adobe 的切换成本软得多，热度丢了就会塌（参考 Under Armour 2016–2019 的教训）。

**ROIC 20.2% 是最重要的护城河印记**：即使在 FY25 利润触底，Nike 仍然赚到远高于资本成本的回报——这说明护城河**没有被摧毁**，只是被 Donahoe 的战略失误和宏观压力压窄了。审计的任务是判断护城河是**可修复的收窄**还是**结构性缩短**。

**五大护城河维度**（消费品牌适配版）：

| 维度 | 含义 | Nike 适用性 |
|---|---|---|
| **品牌 IP / 文化热度** | 消费者愿意为 Swoosh 支付溢价的心智占位 | **最核心**，分品类强弱完全不同 |
| **规模经济（营销侧）** | $4.7B Demand Creation 摊到全球 = 单位成本优势 | 中等，社媒降低了营销壁垒 |
| **运动员/赛事版权** | NBA/NFL/FIFA 官方合作 + LeBron/Kipchoge 等签约 | 强，长期合同难以复制 |
| **习惯性复购** | Nike 跑步者重购 Nike 的行为惰性（最接近切换成本） | 弱-中，切换摩擦为零 |
| **供应链规模** | 97 家工厂/11 国，谈判筹码与柔性 | 中等，被越南关税敞口部分抵消 |

### 战场 A —— 性能跑步（Performance Running）

#### 现状快照

|---|---|---|

| **On Holdings** Q1 2026 净销售 | CHF 831.9M（+14.5% YoY，+**26.4%** constant currency） | On Holdings 6-K，2026/5 |

| **Hoka（Deckers）** FY2026 年全年收入 | $2.59B（+**16%**），"在美国公路跑步品类继续扩大市场份额" | Deckers 8-K，2026/4 |
| **New Balance** FY2025 年全年收入 | $9.2B（+**19%**，第五年连续两位数增长），北美 +20%、欧洲 +30% | NB 2026/2 公告 |
| **Nike 北美跑步品类** FY26 Q2（Sep–Nov 2025）| **+20%+**（YoY） | Nike FY26 Q2 earnings call |

**扫盲：为什么跑步护城河最难守？**
- 跑步是**功能导向**的买决策：消费者会因为"这双鞋真的让我跑得更快/更舒服"而换牌子，不会因为"我一直穿 Nike"而忍受差鞋。这和"穿 Air Force 1 上街"的生活方式逻辑完全不同。
- On 和 Hoka 的崛起不是靠"更酷"，而是靠**真实的产品差异化**（On 的 CloudTec 中底体验、Hoka 的厚底缓震）打进专业跑者群体，再从专业跑者扩散到大众。
- Nike 的反制：Vaporfly（碳板竞速）和 Pegasus 系列仍然是跑步界最认可的品牌之一，但执行管线在 Donahoe 时期**被压制了**。

#### 护城河评分

**ERODING → STABILIZING（侵蚀中，但有筑底信号）**

| 评分依据 | 看空 | 看多 |
|---|---|---|
| **品牌 IP** | On ($4B+ 品牌规模 + 26% 恒定货币增长)、Hoka ($2.6B +16%)、NB ($9.2B +19%) 三家都在高速增长，每一家都在从 Nike 手里拿份额 | Nike 北美跑步 Q2 FY26 **+20%+**，说明 Hill 重新激活了性能品类 |
| **运动员版权** | On 签约 Sifan Hassan（世界纪录保持者）；Hoka 在精英耐力运动员中口碑好 | **Kipchoge 是 Nike 人**（Breaking2、马拉松世界纪录），碳板跑鞋的技术叙事源头在 Nike（Vaporfly） |
| **规模经济** | On 的营销效率极高（CHF 3.5B 营收却花极少广告费，靠口碑）；NB 欧洲 +30% 证明规模不是全部 | Nike $4.7B 营销规模让它能同时支撑多个跑步子品类（竞速 + 日常训练 + 越野） |
| **习惯复购** | 跑步消费者"试了 On 以后就回不去"的用户评论是真实的；Piper Sandler Fall 2025：On 超越 Hoka 成为青少年"最想要跑鞋品牌" | Nike 依然有 Pegasus 用户的强烈忠诚度（已经跑了 40 代） |

**关键判断**：On 和 Hoka 已经在高端公路跑步（$150+）建立了 **稳固滩头**，这部分份额**不会自然还给 Nike**，需要 Nike 主动用产品打回来。Hill 开始的性能品类重投 + 北美 Q2 +20% 是正面信号，但竞品增速（On +26% 恒定货币）仍然快于 Nike 的修复速度。

> **分品类护城河宽度：跑步 = 中等 → 正在收窄（尚未断裂）**

### 战场 B —— 篮球 / Jordan Brand（Basketball / Jordan）

#### 现状快照

| 指标 | 数字 | 数据来源 |
|---|---|---|
| **Jordan Brand FY25 收入** | $7.27B（−**16%**） | Nike FY25 10-K |
| **Jordan 二级市场份额**（StockX） | **28%**（连续三年 StockX 最畅销品牌之一） | StockX 2025 Big Facts Report |
| **Jordan 转售平均价** YoY 2025→2026 | **+6%**（价格正在修复） | StockX 2025 Current Culture Index |
| **Nike 转售平均价** YoY | **+5%** | StockX 2025 Current Culture Index |
| Air Jordan 11 Space Jam 2026 假日款 | 已宣布，限量版，稀缺策略执行中 | 公开媒体报道 |

**扫盲：为什么篮球护城河最宽？**
- **Michael Jordan 的遗产是无法复制的 IP**。Air Jordan 1（1985 年）=历史上最具文化影响力的运动鞋，和它竞争等于和历史竞争。没有任何对手能再创造一个"1985 年的 Michael Jordan"。
- Jordan Brand 的商业模式 = **稀缺性 × 文化传承 × 球星资源**。它每发布一款限量 Retro，就消费了一次 MJ 的遗产；但如果每次都限量，这个遗产可以无限期使用。
- **Donahoe 的罪行**：为了喂 DTC 渠道，把 AJ1/Dunk/AF1 发到泛滥——结果二级市场溢价从高峰期的 100%+ 跌到部分款式的溢价消失。这是**品牌IP 的自我稀释**。
- **Hill 的修复**：更少发货、更严格限量、更好的叙事（AJ11 Space Jam 2026 提前布局）→ 转售价格已经开始反弹 +6%。

#### 护城河评分

**STABLE → RECOVERING（稳定，正在修复）**

| 评分依据 | 看空 | 看多 |
|---|---|---|
| **品牌 IP** | Donahoe 时期过度发货损伤了"稀缺感"，Z 世代里 AJ1 不再是必抢款 | Michael Jordan 的 IP 是**护城河里最难复制的资产**，历史上从未有任何运动员品牌能接近；加上《The Last Dance》2020 一代经典，文化共鸣是跨代的 |
| **竞品威胁** | Anta + 欧文签约：欧文 2023 离开 Nike → Anta，对篮球鞋市场的争夺在加剧；adidas 有 Harden | Nike 依然是 NBA 官方合作伙伴，穿 Nike 上场的球星数量压倒性领先 |
| **财报数字** | FY25 Jordan −16%，比公司整体 −9% 差很多，说明 Donahoe 的伤害实打实 | 转售价格 +6% 是**先行指标**（市场在 price in 稀缺修复早于财报数字）；Hill 的策略改变从 FY26 才开始生效 |
| **生意逻辑** | Jordan Brand 毛利更高（内部估计 >Nike Brand 平均），过度发货等于把最赚钱的资产用最差的方式经营 | Hill 的稀缺策略修复 Jordan 是**最高回报的单一动作**——收益在几十亿美元级别 |

> **分品类护城河宽度：篮球/Jordan = 强（Nike 内部最宽的护城河）**

**扫盲：生活方式护城河为什么最难判断？**
- 生活方式鞋的护城河本质是**时尚周期**，而时尚周期没有固定护城河。Samba 这轮潮流持续到第五年（2020–2025），比典型的 2–3 年周期长，但终究会退潮。
- NB 的成功说明一件重要的事：**"文化冷却、重新变酷"是可以做到的**（NB 在 2010s 是 dad shoe 笑话，2020s 成为 $9.2B 高端品牌）——这对 Nike 既是警告（品牌热度可以被反转），也是希望（Nike 自己也可以重新变酷）。
- Nike 目前生活方式的问题：**AF1、Dunk、Air Max 都被发滥了，稀缺性近乎为零**。Hill 正在收缩发货量，但修复稀缺感需要 2–3 年。

#### 护城河评分

**ERODING（侵蚀中，短期内无法逆转）**

| 评分依据 | 看空 | 看多 |
|---|---|---|
| **品牌 IP** | adidas Samba/Gazelle 已经接管了"生活方式首选"的心智，且五年周期未见拐点；NB 成功实现溢价跃迁，ASP 从 $60→$80 | Nike 依然在生活方式鞋里有全球认知度；AF1 / Air Max 90 是永恒经典，只是现在被发烂了 |
| **供给控制** | Nike 错过了收缩发货的时机，复刻款过度铺货已经在消费者心里形成"随处可见"的印象，短期很难洗掉 | Hill 已经开始收缩，StockX 上 Nike 整体转售价 +5% 是早期信号，转售市场先于财报反映 |
| **竞争格局** | adidas Retro + NB Retro Running 是**同步增长、同步抢生活方式份额**，两家加在一起的体量和势能远大于单一对手 | Nike 在生活方式里没有真正"只有它能做"的单一资产（Jordan 除外，Jordan 已单独计分） |

> **分品类护城河宽度：生活方式 = 中等偏弱，当前处于侵蚀期**

| 管理层表态 | "大中华需要**更长时间**" | Hill，FY26 Q3 earnings call |

**扫盲：中国为什么是最复杂的战场？**

中国同时叠加了**四个逆风**，每个单独都是麻烦，四个加在一起很沉重：

1. **国潮/消费者情绪**：外资品牌 ≠ 自动高档，2021 年新疆棉事件后 Nike/adidas 遭到抵制情绪（虽然已减弱，但记忆还在）。
2. **Anta 的实力追赶**：Anta 在 FY2025 全年营收 $11B，以真实业绩**超越了 Nike 的大中华**。更重要的是，Anta 的研发和设计水平在过去 5 年显著提升，"国货不如洋品牌"的质量偏见正在消退。
3. **消费降级大背景**：中国消费者在运动鞋溢价支付意愿整体下降，有利于性价比更高的本土品牌。
4. **Li-Ning 的叙事**：李宁靠"中国李宁"系列（2018 纽约时装周），成功把国潮叙事和运动 IP 结合，从 Nike 的低端对手变成真正的品牌竞争者。

**这是永久台阶下移还是周期？**

目前证据倾向**结构性**（不是纯周期）：
- Anta 以业绩反超 Nike 大中华，说明这不只是品牌声量问题，而是真实消费者决策的转变。
- 国潮情绪有韧性（5 年了，未见明显回摆）。
- 但：Nike 大中华分部利润率历史上是全球最高（24.3% 分部 EBIT 率），说明它在中国卖的是**溢价**。只要中国高端消费在，Nike 不会消亡，但份额重心会永久下移。

#### 护城河评分

**ERODING（结构性侵蚀，非周期性）**

| 评分依据 | 结构侵蚀证据 | 周期企稳的反驳 |
|---|---|---|
| **品牌 IP** | Anta 已在中国本土运动鞋服超越 Nike 收入规模；国潮叙事 5 年不退潮 | Nike 的全球 Swoosh 品牌形象在中国一线城市高净值消费者中仍有独特吸引力 |
| **规模经济** | 本土品牌在中国本地制造 + 营销更高效；Anta + Li-Ning 可以调配中国工厂快速响应 | Nike 全球供应链规模和研发投入绝对量级仍远超 Anta |
| **运动员版权** | Anta 签约欧文（篮球）、多位国家队运动员（中国受众共鸣更强） | Nike 在中国依然拥有多数顶级运动员代言 |
| **习惯复购** | 年轻消费者入坑 Anta 后重购 Anta → Nike 的新客获取在中国在萎缩 | 存量 Nike 用户忠诚度仍在，但这是存量效应 |

> **分品类护城河宽度：大中华 = 弱，且正在持续收窄（结构性）**

## 2. 汇总评分表

| 品类 | 护城河宽度 | 趋势 | 核心驱动力 | 反转所需 |
|---|---|---|---|---|
| 篮球 / Jordan | **强** | STABLE → RECOVERING | MJ 遗产不可复制；Hill 恢复稀缺 | 管理层持续执行稀缺策略，勿再重蹈 Donahoe |
| 性能跑步 | **中等** | ERODING → STABILIZING | On/Hoka 已抢滩，但 Nike 跑步 Q2 FY26 +20%+ 修复中 | 性能创新管线必须持续输出，不能再断档 |
| 生活方式 | **中等偏弱** | ERODING | adidas +13%、NB +19%，两家同步抢份额 | 收缩过度铺货、等 adidas 周期转，需 2–3 年 |
| 大中华 | **弱** | ERODING（结构性） | Anta 已超越、国潮持续、消费降级 | 需要产品和本地化叙事系统性重建 |
| 女子/训练 | **中等** | STABLE-to-ERODING | lululemon/Alo 持续蚕食高端女子 | Nike 需要专属女子产品线，目前执行薄弱 |
| **公司整体** | **中等偏强** | **STABLE-to-ERODING** | ROIC 20.2% 印证护城河未被摧毁；但正在收窄 | Jordan + 跑步 + 营销投入是三个可控变量 |

**一句话结论**：Nike 的护城河**没有断裂，但正在变窄**。断裂线是大中华和生活方式，压舱石是 Jordan Brand。ROIC 20.2% 是关键提醒：一家没有护城河的公司在利润触底时 ROIC 早就跌到资本成本附近，而 Nike 还在 20%——说明品牌特许权依然存在、只是宽度缩减。

## 3. 护城河情景（Bull / Base / Bear）

### 🐂 Bull Case —— "Hill 修复超预期，Jordan 复苏引领"

**前提**：Jordan 稀缺策略在 FY27 以后开始在财报里体现（Jordan Brand 重回 +5%~+10%）；跑步 +20% 北美趋势持续并扩展到 EMEA；品牌营销 $5B 投入的"ROI 拐点"在 2026–27 出现；大中华触底后微幅反弹（−5% → 0%）。

**护城河演变**：
- 篮球/Jordan: widening（稀缺修复 → IP 价值提升 → 定价权恢复）
- 跑步: stabilizing（Hill 的性能品类投入 → Vaporfly 继续领先 → 份额稳住）
- 生活方式: stable（adidas 周期 3 年内拐点）
- 中国: stable at lower level（不再恶化，以低基数为基础）

**隐含 ROIC 路径**：FY25 的 20.2% → FY27/28 恢复到 22–24%（EBIT 率从 8.2% → 11–13%）

---

### 🐻‍ Base Case —— "护城河稳住但不扩张，转型进度符合 Hill 的说法"

**前提**：Jordan 品牌 FY26–27 在稀缺修复下财报数字从 −16% 恢复到 0~+5%；跑步份额输给 On/Hoka 但速度放慢（Nike 跑步从 +20% 稳定下来）；生活方式继续输份额但不崩；大中华在 −5%~−10% 区间波动，不再加速恶化；毛利率 FY26 全年 41~42%，FY27 开始向 43~44% 回升。

**护城河演变**：
- 公司整体：STABLE-to-ERODING，宽度维持但不复 2018 年状态
- ROIC：20%±2%，维持特许权印记但不扩张

---

### 🐻 Bear Case —— "护城河正在永久收窄，复苏不可持"

**前提**：On/Hoka 在跑步市场的份额侵蚀加速，连北美反弹也只是短暂的；Jordan 过度发货的伤害比预期更深（Z 世代对 AJ 的热度永久降档）；大中华 Anta 全面超越 → Nike 从"运动首选"降级为"可选品牌之一"；全球消费降级 + 关税双压 → 毛利率维持在 40~41%，无法回到 44~45%。

**护城河演变**：
- 篮球/Jordan: eroding（文化热度永久降档，过度发货的影响无法修复）
- 跑步: eroding（On 品牌知名度和 NB 性能口碑在年轻跑者里固化）
- 生活方式: eroding（adidas 周期持续超过预期，Nike 生活方式 IP 价值进一步稀释）
- 中国: structural collapse（ Anta 和 Li-Ning 成为中国消费者默认选择，Nike 降为第三选择）

**隐含 ROIC 路径**：FY25 20.2% → FY27/28 降至 14–16%（EBIT 率新常态 9–10%，非 8% 周期底，也非 13% 历史峰值）

## 4. 护城河审计的核心结论（给估值阶段用）

1. **护城河没有断裂，但已经收窄**。最强的证据：ROIC 20.2%（FY25 利润触底 + ROIC 仍是这个数）。这是 Greenwald 消费特许权的签名。

2. **护城河强弱高度分化**：Jordan = 最宽（文化 IP 不可复制）；跑步 = 有修复迹象（但 On/Hoka 已建立滩头）；生活方式 = 正被 adidas/NB 分食；中国 = 结构性收窄（Anta 已超越）。

3. **估值阶段的参数含义**：
   - **Bull**：EPV 基于利润率恢复到 12–13%，Jordan 品牌资产重新上升，品牌 AV 高于平摊 Demand Creation。
   - **Base**：EPV 基于正常化利润率 10–11%（历史 12% 的折扣），反映中国永久台阶下移 + 生活方式护城河收窄。
   - **Bear**：EPV 基于"新常态" 9–10% 利润率，品牌资产折价，无 franchise value 附加。

4. **两个领先指标**（每季财报要盯）：
   - **Jordan Brand 收入 YoY**（稀缺修复的最直接信号）
   - **大中华收入 YoY 趋势**（结构性侵蚀 vs 周期触底的判别器）
