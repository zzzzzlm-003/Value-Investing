## 一、本次改动（已完成）

### 1) 估值底层逻辑修正（对标课件）
- EPV 非经常项调整支持直接覆盖键 `extraordinary_adjustment`（此前仅支持列表项，UI 编辑值不能正确传入）。

- 增长支出方法真正落地：支持 `method1` / `method2`（此前前端有选项但引擎未分支执行）。
- FV 增加 `strict_course_mode`：
  - 严格模式按课件主式计算；
  - 允许 `ROIC < WACC` 时得到负 FV（增长摧毁价值）。
- 报表年份一致性修正：选择 `T/T-1/T-2` 后，历史序列旋转到索引 `0`，避免计算器默认读取 `[0]` 造成错年。

## 三、必须检查项（继续对课件）

1. **ROIC 分母口径**
- 是否始终按课件要求处理 `AccDep/AP/Accrued` 的符号与缺失替代。

2. **WACC 表格一致性**
- `we/wd`、`re/rd`、税后债务成本是否与课件表格逐行一致。

3. **增长率 g 处理**
- `g = k × ROIC + organic` 的实现与上限策略是否符合课件语境。
- 严格模式下避免引入额外 heuristic cap。

4. **FV 负值逻辑**
- 严格模式下 `ROIC < WACC` 必须允许负 FV。
- 非严格模式可保守处理，但需在 UI 明示。

5. **EPVc 终止风险**
- `r* = r + p`（或 λ 方案）是否与课件举例一致，页面说明需完整。

## 四、行业特殊项目检查清单（新增模板时用）

### 零售（WMT/COST）
- 租赁（ROU）与门店维护资本开支拆分；同店增长与库存口径。

### 软件/SaaS（MSFT/CRM）
- 高 R&D 资本化讨论；SBC（股权激励）是否单独处理。

### 半导体（NVDA/TSM）
- 超常增长期与回归期设定；设备折旧与先进制程资本强度。

### 银行/保险
- 传统 ROIC/WACC 适配性弱，需专项口径（监管资本、准备金）。

### 公用事业/电信
- 重资产+高杠杆，折旧与准许收益（Regulated Return）影响大。
